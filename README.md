# 📦 interactive-copy

interactive-copy is a simple Python script that allows you to copy text to the clipboard interactively. It uses the `pyperclip` library for clipboard operations and `uv` for an interactive command-line interface.

## 🚀 Usage

```sh
uv sync
uv run main.py
```

## ⚙️ Dependencies

- [uv](https://docs.astral.sh/uv/)
